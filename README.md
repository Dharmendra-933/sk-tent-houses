# SK Tent House & Decorator — Premium Website

A responsive, multi-page business website designed for **SK Tent House & Decorator**, Bargaon, Kotharam, Darbhanga, Bihar.

## Pages / sections included
- `index.html` — Home / landing page
- `about.html` — About Us
- `services.html` — Service details
- `gallery.html` — Gallery
- `contact.html` — Contact details and quick enquiry form
- WhatsApp floating contact button

## Features
- Premium navy-and-gold visual identity
- Responsive mobile navigation
- CSS 3D hover tilt, floating elements and scroll-reveal animations
- Quick enquiry form opens WhatsApp with the user's details
- No build tools, framework, or backend required
- Includes a promotional poster asset in `assets/`

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `sk-tent-house-website`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site.

## Before publishing
- Confirm phone numbers, address, proprietor name, and service details.
- Replace remote sample photos with your own event photos when available. The current photo URLs require an internet connection.
- This is a static website; the contact form does not save enquiries to a database. It opens WhatsApp with the enquiry pre-filled.
- To change the WhatsApp destination, edit `917462929480` in `index.html` and `script.js`.
